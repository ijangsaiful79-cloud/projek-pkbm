Program Kami

Program Kesetaraan

Tiga jenjang pendidikan resmi dengan satu tujuan: membuka peluang lebih luas untuk masa depanmu.

Paket A

Setara SD/MI

Untuk yang belum tuntas pendidikan dasar. Bebas usia, dapat melanjutkan ke Paket B.

  • Ijazah resmi negara
  • Bebas usia dan domisili
  • Jadwal fleksibel
  • Tutor berpengalaman
Selengkapnya
Paket B

Setara SMP/MTs

Untuk lulusan SD atau Paket A yang ingin melanjutkan ke jenjang menengah pertama.

  • Ijazah resmi negara
  • Diakui untuk melamar kerja
  • Jadwal fleksibel
  • Dapat lanjut ke Paket C
Selengkapnya
Paling Diminati
Paket C

Setara SMA/MA

Untuk pekerja aktif, atlet, dan pelaku industri kreatif. Bisa mendaftar PTN via SNBT.

  • Daftar PTN via SNBT
  • Untuk CPNS, TNI, POLRI
  • Kenaikan jabatan karir
  • Biaya dapat dicicil
